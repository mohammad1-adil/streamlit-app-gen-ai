# Streamlit App Gen AI

A simple Streamlit application that demonstrates the basics of building a Python web app with Streamlit.

## Overview

This project contains a minimal example app that includes:

- page configuration
- page title and icon
- wide layout
- title, header, and subheader sections
- text content
- Markdown rendering
- caption text

## Project files

- `streamlit.py` - the main Streamlit application

## Run locally

1. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies:

   ```bash
   pip install streamlit
   ```

3. Start the app:

   ```bash
   streamlit run streamlit.py
   ```

4. Open the local URL shown in the terminal, usually:

   ```text
   http://localhost:8501
   ```

## Example app content

The app showcases a basic Streamlit interface with a title and text sections, such as:

- "Python Applications Crash Course"
- "Streamlit Basics"
- a short explanation of what Streamlit is
- Markdown content
- a caption section

## Requirements

- Python 3.8+
- Streamlit
